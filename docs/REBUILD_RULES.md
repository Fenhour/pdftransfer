# 当前重建规则（2026-10-29筛选副本）

以下从原项目2026-10-29规则说明摘取当前算法及未来迁移边界；不包含历史封存路径和旧耗时报告。

## 07：空间关系与阅读顺序分开计算

输入包括plus-L的块ID/类别/坐标、BlockLayout的Region框、det的行框、rec回填文字，以及前期已确认的容器/组合块。Region不是语义容器，也不会直接当背景。容器关系由源像素和闭合边框等依据先建立，最终07再以最终模块身份汇总。

1. 父子树先检查ID重复与循环；子项只能有一个可见归属。只有顶层块参与页面阅读排序，容器内部不重复进入页面序列。
2. Region按页面像素→pt换算；IoU至少.95去重复框；嵌套框优先外框；相互交叠的非嵌套Region不作为可靠隔离边界。普通块覆盖率至少90%、图片99.5%，且只能有一个候选。Region若还明显碰到不归它的内容（交叠超过该外部块5%），拒绝该隔离框。65%以上的弱覆盖可作为hint，不等于强制归属。无可靠归属退回页面框；页面已有可靠Region时，未归属块在08中独立处理，不推动已隔离区域。
3. `source_order`：页面顺序优先，页内递归XY切割，先找大于8pt的左右空隙形成栏目，再找大于3pt的上下空隙形成阅读带；一般取最大空隙，跨栏宽块所在的上下分界优先。无可靠空隙退回y、x、ID稳定排序。它是几何阅读参考，不是语义理解模型。
4. `spatial_edges`：仅同frame内推断上下/左右可见邻居。横向/纵向投影重合至少20%，分离间隔非负，中间没有挡住主要共同投影带的其他块。记录双方ID、`above/left_of`、实际间距pt、间距/frame尺寸比例、投影重合与依据；不为每块强凑四个邻居，也不把相邻自动变成硬阅读顺序。
5. 标题/图表题寻找局部附着：上下邻接投影至少50%，间距不超过`max(24pt, 标题块高度×2)`。标题只能关联下方非标题；图表题关联图片/图表/表格。最近候选若与次近候选差距小于等于`max(3pt, 最近间距×.2)`，视为歧义。无歧义且投影至少80%才生成强附着和`hard_before`，其他只保存`soft_before`。先后方向按几何`source_order`确定，不猜标题文字语义。
6. 已有显式hard约束优先，先验证有效引用和无环；推断边逐条加入，若会与显式约束形成循环就降为软依据。08用稳定拓扑排序得到最终阅读序，优先维持`source_order`。`hard_before`不会直接规定物理坐标，也不用于碰撞方向计算。

主要代码：`transfer_kernel_ocr/backend/spatial_relations.py`中的`_page_frames`、`_xy_order`、`_spatial_edges`、`_attachments`、`derive_spatial_relations`。

## 第一层：块内部测量和自适应

定位证据来自det的源行框，rec只回填文字；`line_id/block_id`保持文字和源几何对应。文字局部坐标由“行框坐标减块左上角”换算到pt。目录片段、表格cell也使用同样的源锚点换算，没有逐字位置或原始字体恢复保证。

- 正文/目录按基线容差聚行、同行按x排片段，保留源左边、首行缩进、行间距和独立页码锚点。语义段落另存，物理行不先扁平化。普通正文不因跨页面中心误判居中；有证据的对齐以源行自己的中心/右缘为参考。
- 使用角色模板字体和实际安全字体度量。块内采用共同字号；宽度不足时可最多保守降15%，通常不低于7pt（源字号本来更小时不放大），仍不足只对该片段换行。只在真实字形高度冲突时后移下一行，不挤压字形。
- 表格先保拓扑，再将OCR唯一分到cell；与该格HTML去空白字符顺序完全一致才取源行/位置，保留原HTML。可靠源行高、列宽依据、合并格和常见对齐证据保留；匹配不可靠则记录诊断，保留模型文字与原图参考，不假称恢复了位置。
- 图片保持像素宽高比；已确认容器保留子项相对偏移及背景/边框一起测量。
- 默认高度为`max(源块高度, 重建内容需要高度)`。内容变小保留原外框和留白，增长才向第二层报告。测量保存字体、字号、x、baseline、行范围/身份和签名，PDF/HTML直接使用，不导出时重新猜排版。

主要代码：`source_text.py`、`source_table.py`、`adaptive_layout.py::measure_block`、`regional_layout.py::measure_source_composite`。

## 第二层：Region内放置与有界适配

1. 每块先放回源位置、源宽度，块内高度使用第一层结果；无冲突不移动。新版本保持源页一对一，默认不改成单栏、不增加分页。旧项目的flow兼容分支仍保留。
2. 发生碰撞时依据**源空间方向**在同frame内下移/右移邻居，先消耗已有留白；必要安全间距不超过2pt，不强求原来的大间距。方向无法证明的原始重叠明确报错；经过严格像素所有权验证的透明图片组合是单独例外。
3. 计算该Region重建内容外包框。越界时统一缩放整个Region，`s=min(1, Region宽/内容外包宽, Region高/内容外包高)`，位置/字体/表格/容器一起等比缩放。默认缩放下限.85，字号通常不低于7pt；其他Region保持不动。
4. 只有**实际越界且整体缩放低于可读下限**，才尝试释放顶层文字块尾部未使用外框，保持内部行/片段间距，不缩表格行高、不缩图片/容器背景。重新计算碰撞和整体缩放；只有改善且达标才接受，保存触发原因/块ID/首次缩放因子。
5. 仍不达标明确报错，不跨Region挤占、不无限缩字。最终检查完整归属、顺序图、内容范围、拓扑、边界及新重叠。

主要代码：`regional_layout.py::_arrange/layout_regions/scale_measurement`，导出校验`adaptive_export.py`。这是一套“源几何优先＋有界修正”规则，尚不是通用约束优化器。

## 后续位置/样式识别的设计预警

用户计划让rec（原消息rev）输出更细文字位置，后续可能增加样式识别。当前封存版继续使用det行/片段位置，不在此轮替换成尚不存在的rec坐标。未来模块位置可能来自识别模型、det或原生PDF，必须明确来源、粒度、坐标系、置信度与变换链；若rec在校正/拉直后的裁片上输出词/字符框，需逆变换回源页，不能直接与page-pixels混用。

样式识别改变字体、字号、字重与行高，都会改变实际字形宽高。因此下一版先更新统一内容/样式/几何契约，再重测第一层；第二层是否继续“保原框＋区域等比缩放”需用真值验证，不能默认照搬15%/.85/7pt等阈值。源观察几何、目标测量几何和约束依据应分存，保留原始识别证据；不把当前规则写成对未来模型接口的永久要求。本轮只记录迁移边界，没有开始微调/引入新模型或实现新算法。
