# 转换流程

可编辑 PDF 的 HTML / Markdown 输出复用原生文字、坐标、图片和表格；网页入口关闭扫描 OCR，避免把原生文字重复识别和绘制。每次生成所选格式的 ZIP，包含相对链接所需的资源和源 PDF。

扫描 PDF 与图片由本地 PP-StructureV3 处理：版面类别与区域检测、全页文字行检测、唯一归属与组批识别、表格拓扑恢复。源框、行 ID、表格结构和原图参考保留，测量与导出使用相同字体和坐标快照。

重建保留源页及版面关系，按文字、块、大区域分层适配。多栏顺序、标题角色、文本对齐和重叠文字去重属于几何后处理，不能替代人工准确率评测。图片整体保留，不把图中文字重复作为独立正文。表格结构不可信时保留原图或待校对结构，不能视为成功恢复。

区域布局无法继续时保存当前几何及诊断，继续其它区域和后续页面。导出遇到组合块内部或顶层内容块重叠时同样保留现有位置和文字，结果标为布局待复核；内容遗漏、重复 ID、无效坐标和文字与测量不一致仍会报错。

| 路径 | 职责 |
| --- | --- |
| `transfer_kenel/pdf_extractor/` | 原生 PDF 读取、分类、阅读顺序与 HTML / Markdown 导出 |
| `transfer_kernel_ocr/backend/` | 本机 HTTP、转换队列、源结构测量、自适应排版与 PDF 导出 |
| `transfer_kernel_ocr/frontend/` | 三种转换方式、上传、下载与逐页预览 |
| `services/structure_v3/` | 独立 V3 子进程、官方模型准备、文字/表格分支及性能记录 |

`region_recovery.py` 是运行时恢复逻辑，直接作为后端模块导入。模型初始化与批次日志记录真实执行耗时，缓存命中不计为模型推理。输入、输出、权重与日志均在本机生成，不纳入 Git。
