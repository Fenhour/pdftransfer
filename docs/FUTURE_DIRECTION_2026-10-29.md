# 后续方向：位置、样式与分层残差对齐

整理日期：2026-10-29。本文描述未来目标和待验证研究问题，不代表已实现或通过验收。

## 目标与当前基线

后续重点是补充OCR输出的几何和样式信息，让重建不仅保存文字内容，还能保留块内缩进、连续文本段、空白及块间相对位置。最终希望支持更准确的可编辑文档重建，包括后续Word方向；这不是当前已具备Word导出或原字体恢复能力的声明。

当前基线仍为 `v2.2026.10.28-internal-structure`：文字位置来自det行/片段框，通过line_id与rec文字对应；第一层使用源行、目录片段和可信格内锚点加模板字体测量，第二层在可靠Region内有界适配。rec尚未直接输出逐字位置，也未接入字体分类模型。07负责关系与顺序，08内部包含两层自适应，不能把07和08各当成一层。本文不替换当前实现规则。

输入、版面类别与Region检测的总体路线作为起点保留，重点研究OCR证据及重建环节；是否调整模型接口、粒度和约束，应依据后续验证决定。

## 一、补充OCR的几何与样式输出

1. **位置**：除文字内容外，保存相对所属块/单元格的行、连续文本段位置，研究词/字符级位置的必要性与可行性。每个结果明确来源（det、rec、原生PDF或推断）、粒度、坐标系、置信度和变换链。
2. **样式**：研究字体家族、字重/粗斜体、字号、行高等属性，保留缩进和连续空白的几何证据。OCR字符词典主要编码字符，不等于同一字符各字体/字号的独立样式标签；样式应有单独字段或识别任务。
3. **连续文本与ID**：为连续文本段建立稳定ID，关联上级块、源行、识别文字、起止锚点和样式引用；识别、测量、对齐与导出沿用同一身份，避免排序或分批后错配。
4. **样式集**：集中保存 `style_id`、样式名称、大小和属性，元素引用样式；同时分存“观察到的样式”和“实际采用的安全替代样式”，不能把模板/推断值当已识别的原字体。

笔记提出的“首字左上角＋文字数量×样式大小”可作为实验假设，不能直接作为准确逐字定位方法：比例字体、字偶距、标点、基线、粗斜体、混排和换行都会改变位置。字号也不等于每个字的实际前进宽度。优先验证连续段起止锚点和实际字体度量是否已足够，再决定是否需要逐字识别/微调，避免过细修正放大偏差。

## 二、统一分层坐标与证据契约

目标层级为 **页面 → 大区域（Region）→ 块 → 块内元素/连续文本段**；表格在块与文字之间增加单元格层。各层局部坐标以直接父级左上角为原点，同时保留源页坐标和完整变换关系。

建议先讨论的数据字段如下，尚未成为生产接口：

| 对象 | 拟保留的信息 |
| --- | --- |
| Region/块/单元格/文本段 | 稳定ID、parent_id、源页身份与归属证据 |
| 源几何 | bbox/多边形、连续段起点/终点、基线、单位、坐标系、来源与置信度 |
| 变换 | 裁片到页、旋转/拉直/缩放到源图的逆变换；父子局部到页面变换 |
| 样式 | style_id、名称、字号/度量属性、观察来源、实际替代与原因 |
| 目标几何 | 重建测量结果、当前放置、变换、锚点差值及修正记录 |

源观察与目标几何分开存储。若rec在拉直后的裁片中返回位置，必须逆变换回源页后再建立父级局部坐标，不能直接与原页det框相减。起止点的定义也需固定，例如墨迹边界、基线起点或排版前进位置，避免比较不同含义的坐标。

## 三、设计两层自适应中的残差对齐

笔记的核心设想是比较对应对象的源相对位置与重建相对位置，用差值修正重建偏移。为便于后续讨论，可约定 `残差 = 目标局部锚点 − 源局部锚点`；按负残差修正只是候选操作，不能绕过内容、碰撞和边界约束。单位/缩放不同须先归一到相同坐标空间。

### 第一层：块内自适应

- 比较同一ID的连续文本段起止点、基线及其相对父块/单元格的位置，保留缩进、片段间空白和源行关系。
- 用识别或替代字体的真实度量重建，分别观察起点偏移、终点偏移、宽高/换行差异。只把首字拉正不能证明整行或整块恢复。
- 研究不同程度残差的处理：容忍小误差、平移锚点、调整可变空白、重新测量/换行，或在有证据时采用其他受限修正；阈值、优先级与是否允许局部缩放尚待实验确定。
- 保存修正依据、前后残差与失败原因；不以逐字强行拉伸或堆叠把坐标凑齐，不丢字、不覆盖源证据。

### 第二层：块间/Region自适应

- 将同一思路应用于块相对Region的位置，结合源顺序、空间邻接和父子关系处理，不能独立拉动每个块而破坏结构。
- 笔记提出的**待验证候选顺序**：越界时先研究整体平移（例如下溢时尝试上移），平移不可行再整体等比缩小；仍不满足时，研究释放块内真实未使用留白、减少外框高度并沿相应方向重新对齐。
- 上述先后与当前实现并不完全相同，应先评估平移是否引入另一侧越界、碰撞或锚点偏离。压缩只释放经测量确认的空闲空间，不能压掉有效内容、表格行高、图片或容器背景。
- 明确可读性下限、Region隔离、修正预算和无法满足时的校对/失败语义。当前15%、0.85、7pt等数值不自动作为未来模型方案的固定阈值。

这部分目前是算法研究方向，不是已有“通用残差对齐算法”，也没有承诺能通过一次平移消除所有排版偏差。

## 四、顺序规则与候选模型

顺序规则需要与新几何粒度共同明确：页面只排顶层块，子项在父级内排序；空间邻接、阅读参考顺序、强制先后、父子归属分开表示。保留显式约束、无环检查和歧义记录，不能把坐标微调当语义顺序识别。后续评估沿用或调整07的范围，再建立独立版本。

## 建议推进顺序与验收

以下是将笔记落到研究工作的建议，不是已经批准实施的算法细则：

1. 选取有代表性的中英文、混排、缩进、目录、表格与扫描失真样例，建立人工审核的文字、几何、样式、阅读顺序真值。
2. 先确定连续段/词/字符粒度、父子ID与坐标/样式契约，再比较现有det锚点、候选位置方法和字体分类方案。
3. 分别原型验证块内残差与Region残差，保存修正前后证据；检验整体平移/缩放/释放空闲空间的条件与顺序，避免未经比较替换生产规则。
4. 只有确认样式与几何证据有效后，才联合重测字体度量、顺序与两层约束；作为独立新版本保留当前基线和可回退配置。

验收分开记录：文字错误率、位置/基线偏差、字体及属性分类质量、顺序/拓扑一致性、碰撞/越界、可读性和人工编辑体验；性能区分冷启动、字体加载、真实推理和缓存。结构安全检查或“能运行”不能代替准确率；Word/WPS可编辑性须单独实际验证。

笔记中的rec极小参数诊断和版本恢复统计仅作为历史背景：旧段落“生产未修改”是当时诊断状态，当前det/rec已经选择优化派生权重；极小参数具体训练成因不能仅凭权重数值确证。本方向文档不重复旧计时、不修改封存包，也不把旧测试结果写成新算法验收。
