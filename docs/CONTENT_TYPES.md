# 当前内容目标与保留原则

正文/标题/页眉页脚：原生页优先保留原字符和几何；扫描页保留det/rec证据。文字识别、定位、字体和段落结构是不同任务，不以单一模型标签替代全部能力。

表格：保留可验证的原生或模型行列、合并关系、真实文字及原图参考。结构不可靠或所有权冲突时保图并报告，不把图片回退包装成已恢复表格。

图片/组合块：复杂图片保持原图；图内转录是元数据。仅充分证据支持的闭合简单容器参与背景/边框与子项共同测量。未知像素、公式、图表数据、手写与低清扫描不承诺完整恢复。

字体/样式：当前重建采用安全角色模板及源几何约束；系统字体近似不等于识别出原始字体。尚未接入TaCo或DINOv2字体分类器。

新增模型前先建立人工审核真值；位置、文字、表格拓扑、字体样式分别评测。实际限制见 [当前概况](PROJECT_OVERVIEW.md)。
